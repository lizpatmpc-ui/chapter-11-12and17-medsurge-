# Med-Surg 90-Question Interactive Exam

Interactive NCLEX/HESI/ATI/Kaplan-style review exam covering Chapters 11, 12, and 17.

## Features
- 90 questions in the original order
- Single-answer and SATA questions
- Instant correct/incorrect feedback after each submitted answer
- Rationales and textbook-topic support
- NCLEX key points
- SATA partial-credit scoring
- Running score and percentage
- Review missed/partial questions
- Downloadable standalone HTML exam

## Run locally
Download `index.html` and open it in any modern browser.

## Publish with GitHub Pages
A Pages deployment workflow is included at `.github/workflows/deploy-pages.yml`.

In the repository, open **Settings → Pages → Build and deployment → Source → GitHub Actions**. After Pages is enabled, the site URL will use the standard GitHub Pages format:

`https://lizpatmpc-ui.github.io/chapter-11-12and17-medsurge-/`
